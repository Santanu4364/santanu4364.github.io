Web Development and HTML Fundamentals

Personal revision notes on how websites work, the role of front-end technologies, and the essential HTML elements used to build a web page.

1. Understanding Web Development

Web development is the process of creating and maintaining applications that run through the web. It includes planning the structure of a site, presenting information to users, and handling the systems that work behind the visible page.

1.1 Browser and Web Server

  • Web Browser: Software used to open and interact with websites. Examples include Chrome, Firefox, Safari, and Opera.
  • Web Server: A computer system that stores website resources and responds when a browser requests a page.
Simple idea: The browser asks for a page, the server processes the request and sends the required web content back to the browser.

1.2 Front End and Back End

  • Front-end development: Deals with the visible and interactive part of a website.
  • Back-end development: Deals with server-side processing, data handling, and operations that are normally hidden from users.

2. Foundations of Front-End Development

The front end controls how a website is structured and presented in the user's browser. Two basic technologies are HTML and CSS.

  • HTML: HyperText Markup Language. It provides the structural framework of a web page.
  • CSS: Cascading Style Sheets. It controls presentation such as colors, spacing, fonts, and layout.
Memory trick: HTML builds the skeleton; CSS gives the page its appearance.

3. Introduction to HTML

HTML is a markup language used to arrange web content into meaningful elements. Instead of behaving like a general-purpose programming language, HTML uses tags to describe headings, paragraphs, images, links, and other parts of a document.

3.1 HTML Tags

Tags are keywords written inside angle brackets. Many tags appear as an opening and closing pair.

<tagname>Content</tagname>
  • Paired tags: Have an opening and closing tag, such as <p>...</p>.
  • Void or unpaired tags: Do not wrap content, such as <br> and <img>.

3.2 HTML Elements

An HTML element is the complete structure formed by a tag and its content. Elements may also be placed inside other elements; this is called nesting.

<body>
    <h1>Learning HTML</h1>
    <p>This paragraph is nested inside the body.</p>
</body>

3.3 HTML Attributes

Attributes add extra information or settings to an element. They are written in the opening tag, usually as a name-value pair.

<tagname attribute="value">Content</tagname>

Common examples include href for a link destination, src for an image source, and style for inline CSS.

4. Basic Structure of an HTML Document

<!DOCTYPE html>
<html>
<head>
    <title>My Study Page</title>
</head>
<body>
    <h1>Web Notes</h1>
    <p>My first HTML revision page.</p>
</body>
</html>

4.1 The DOCTYPE Declaration

<!DOCTYPE html> informs the browser that the document should be interpreted as modern HTML. It is a declaration rather than a normal HTML element.

4.2 The html Element

The <html> element surrounds the HTML document and acts as its root element.

4.3 The head Element

The <head> section stores information about the document. Much of this information is not directly displayed as page content.

4.4 The title Element

The <title> element defines the text generally shown on the browser tab.

4.5 The body Element

The <body> contains the visible page content, including text, headings, images, and links.

5. Headings and Paragraphs

5.1 Heading Tags

HTML provides six heading levels, from <h1> to <h6>. The first level represents the highest heading level and the sixth represents the lowest.

<h1>Main Topic</h1>
<h2>Section</h2>
<h3>Subsection</h3>

5.2 Paragraph Tag

The <p> element represents a paragraph or block of written content.

<p>HTML gives structure to a web document.</p>

6. Text Formatting

HTML includes elements that can give text emphasis or a particular visual form.

ElementTypical purpose
<em>Marks emphasized text
<b>Displays text in bold style
<i>Displays text in italic style
<u>Underlines text
Example: <p>I am studying <em>HTML</em> today.</p>

7. Styling an Element with the style Attribute

The style attribute can apply CSS rules directly to one HTML element.

<p style="color: navy; font-size: 20px;">
    A styled paragraph
</p>

The general pattern is property: value;. Multiple CSS declarations can be placed inside the same style attribute.

7.1 Background Color

The CSS background-color property changes the background behind an element.

<body style="background-color: lightblue;">
    Page content
</body>

8. Adding Images

The <img> element embeds an image in a page. It does not require a closing tag.

<img src="campus.jpg"
     alt="College campus"
     width="300"
     height="200">
  • src: Specifies where the image file is located.
  • alt: Provides alternative text describing the image.
  • width: Controls displayed width.
  • height: Controls displayed height.

9. Creating Links

The anchor element <a> creates a hyperlink. The href attribute stores the destination.

<a href="https://example.com">Open the website</a>

10. Working with HTML Colors

Web colors may be written in several forms. Browsers understand standard color names as well as numeric color systems.

11. Text Alignment

Older HTML examples often use the align attribute or the <center> tag. In modern pages, CSS text-align is the preferred method.

<h1 style="text-align: center;">Centered Heading</h1>
<p style="text-align: left;">Left aligned text</p>
<p style="text-align: right;">Right aligned text</p>

12. Line Breaks with br

The <br> tag forces the following content onto a new line. It is useful for line breaks inside content, but it should not be used simply to create paragraph spacing.

<p>
    First line<br>
    Second line<br>
    Third line
</p>

13. Preformatted Text

The <pre> element preserves spaces and line breaks from the HTML source. Browsers normally display it using a fixed-width font.

<pre>
Name: Om
Topic: HTML
Status: Revising
</pre>

14. Quick Revision Summary

  • Web development builds and maintains web-based applications.
  • The browser displays a page while a web server provides requested resources.
  • HTML creates page structure; CSS controls presentation.
  • HTML documents are built from elements, tags, attributes, and nested structures.
  • The head stores document information; the body stores visible content.
  • Headings, paragraphs, images, links, formatting elements, line breaks, and preformatted text are basic HTML tools.
  • For modern web pages, CSS is generally preferred over old presentational HTML attributes.
